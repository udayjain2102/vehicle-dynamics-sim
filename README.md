# Vehicle Dynamics Simulator

A MATLAB simulator that models car motion with physics-based equations and control systems to study acceleration, braking, and handling on different road surfaces.

- **Subsystems:** drivetrain, ABS, and cruise control builders composed into one integrated car model.
- **Testing:** an automated scenario test suite, plus interactive driving and 3D animation.
- **Output:** performance graphs and exportable reports.

## Run

In MATLAB, from the repo folder:

```matlab
master_demo
```

Type `README` in the command window for in-tool project notes.
